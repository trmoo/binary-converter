# 정보교과 수업용 웹앱 모음

고등학교 **정보** 수업에서 바로 쓸 수 있는 교육용 웹앱입니다.
앱 하나가 **HTML 파일 한 개**로 되어 있어, 파일을 더블클릭하면 인터넷 연결 없이도 실행됩니다.
(외부 프레임워크·CDN·빌드 도구를 쓰지 않습니다.)

## 앱 목록

### 1. 10진수 ↔ 2진수 변환 학습기 — [`binary-converter/`](binary-converter/)
단원: **디지털 데이터 표현 방법** (수치 정보의 디지털 표현 원리)

| 탭 | 내용 |
|---|---|
| ① 나눗셈 방법 | 2로 계속 나눈 **나머지를 역순으로** 읽는 과정을 표로 한 단계씩 공개. 무작위 연습문제 3개 |
| ② 쉬운 방법 | **자릿값 숫자 카드**를 직접 뒤집어(3D 애니메이션) 합을 맞추는 방법. 목표 수 맞추기, 학습지 문제 5개 |

- 카드 앞면(점 ●)이 보이면 1, 뒷면(빗금)이 보이면 0 — 점이 보이는 카드의 자릿값만 더하면 10진수가 됩니다.
- `이 수를 카드로 만들기` 를 누르면 큰 자릿값부터 한 장씩 뒤집으며
  `16 ≤ 남은 수 27 → 뒤집기! 남은 수 27 - 16 = 11` 처럼 과정을 설명해 줍니다.
- 카드 수를 4장(0~15) / 5장(0~31) / 8장(0~255)으로 바꿀 수 있습니다.
- 정답 확인과 힌트가 들어 있고, 학생 개인정보는 수집·저장하지 않습니다.

## 실행 방법

1. **가장 간단한 방법** — `binary-converter/index.html` 을 더블클릭합니다.
2. **로컬 서버로 열기** — `binary-converter/start-server.bat` 을 더블클릭하면
   `http://localhost:5500/index.html` 로 열립니다. (파이썬만 있으면 됩니다)
3. **저장소를 내려받기** — 초록색 `Code` 버튼 → `Download ZIP` → 압축을 풀고 1번처럼 실행합니다.

## 만들 때의 규칙

- HTML + CSS + JavaScript만 사용하고, 앱 하나는 파일 하나로 만듭니다.
- 화면 문구는 모두 한국어로, 글꼴과 버튼은 교실 TV·전자칠판에서 보이도록 크게 만듭니다.
- 정답 확인·힌트 같은 학습 피드백을 기본으로 넣고, 학생 개인정보는 다루지 않습니다.
- 자세한 규칙과 앱별 개발 기록은 각 폴더의 `CLAUDE.md` 에 정리해 두었습니다.
