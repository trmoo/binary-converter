# 10진수 ↔ 2진수 변환 학습기

고등학교 **정보** 수업의 「디지털 데이터 표현 방법」 단원에서 쓰는 교육용 웹앱입니다.
**HTML 파일 하나**로 되어 있어 더블클릭만 하면 인터넷 없이도 실행됩니다.
(외부 프레임워크·CDN·빌드 도구를 쓰지 않습니다.)

👉 **바로 열기: https://trmoo.github.io/binary-converter/**

## 화면 구성

| 탭 | 내용 |
|---|---|
| ① 나눗셈 방법 | 2로 계속 나눈 **나머지를 역순으로** 읽는 과정을 표로 한 단계씩 공개. 무작위 연습문제 3개 |
| ② 쉬운 방법 | **자릿값 숫자 카드**를 뒤집어 합을 맞추는 방법. 목표 수 맞추기, 학습지 문제 5개 |

### 탭 ① 나눗셈 방법
- 0~255 사이의 수를 넣고 `다음 단계 ▶` 로 한 줄씩 공개하며 발문할 수 있습니다.
- 마지막 단계에서 "나머지를 아래에서 위로 읽으면 …" 결과가 자동으로 정리됩니다.

### 탭 ② 쉬운 방법 (자릿값 숫자 카드)
- 카드 앞면(점 ●)이 보이면 **1**, 뒷면(빗금)이 보이면 **0** 입니다.
  점이 보이는 카드의 자릿값만 모두 더하면 10진수가 됩니다.
- 카드를 누르면 3D 애니메이션으로 뒤집히고, 합계와 `1×2³ + 0×2² + …` 전개식이 함께 바뀝니다.
- `이 수를 카드로 만들기` 를 누르면 큰 자릿값부터 한 장씩 뒤집으며
  `16 ≤ 남은 수 27 → 뒤집기! 남은 수 27 - 16 = 11` 처럼 과정을 설명합니다.
- 카드 수는 4장(0~15) / 5장(0~31) / 8장(0~255) 중에서 고를 수 있습니다.

## 실행 방법

### 수업에서 (설치 없이)
1. 위 링크를 열거나, 내려받은 `index.html` 을 **더블클릭**합니다. 인터넷 없이도 열립니다.
2. `start-server.bat` 을 더블클릭하면 `http://localhost:5500/index.html` 로 열립니다. (파이썬 필요)
3. 초록색 `Code` 버튼 → `Download ZIP` → 압축을 풀고 1번처럼 실행합니다.

### 개발할 때 (Node.js)

```bash
npm install     # 의존성 설치 (Vite)
npm start       # 개발 서버 실행 + 브라우저 자동 열기 → http://localhost:5173/
npm run build   # dist/ 로 빌드
npm run preview # 빌드 결과 미리보기
```

`index.html` 이 개발 서버와 빌드의 메인 페이지입니다.
빌드하지 않아도 `index.html` 하나로 동작하므로, 수업에서는 위의 "설치 없이" 방법을 그대로 쓰면 됩니다.
